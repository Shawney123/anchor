# Anchor · 自制力协议

> A Protocol for Self-Control
> 把《如何提高自制力：CTDP 与 RSIP》中的约束机制，做成一个 Android 上可直接使用的静态 PWA。

**状态：v0.1 可用（核心循环已跑通）**

---

## 这是什么

不是自律激励 App，不是打卡 App，是**约束力工程（Constraint Engineering）**产品。

它把三个可执行机制从人的脑子里搬进系统：

| 机制 | 作用 | 产品形态 |
|---|---|---|
| **神圣座位** | 绑定实体锚点，用工作量证明为专注行为积累约束力 | 链 / 落座 / 节点编号 |
| **下必为例** | 判例法引擎：一次"允许"永久生效，让例外成本显性化 | 判例账本 / 全局永久豁免表 |
| **线性时延** | 预约机制把决策平移到贴现权重平坦区，破解启动困难 | 预约倒计时 / 落座 |

以及 RSIP 的国策树、递归回溯、崩塌调试、熟练度不清零。

**北极星指标**：约束力资源存量（累计点亮国策节点数 + 累计完成链节点数）。不追踪 DAU，不追踪打卡率。

## 技术形态

| 项 | 值 |
|---|---|
| 托管 | GitHub Pages（纯静态，无后端） |
| 端 | Android 优先（Chrome / PWA，已添加到主屏幕） |
| 栈 | Vite 6 + React 18 + TS + Motion + CSS 变量 + IndexedDB |
| 路由 | hash 路由（`#/tree`） |
| 存储 | Local-first：IndexedDB 事件日志 + 导出/导入 .json |
| 依赖后端 | **无**。无账号、无云同步、无推送服务、无第三方埋点 |
| 字体 | 自托管 woff2（Inter / Instrument Serif / JetBrains Mono），中文走系统黑体栈 |

**产物体积**：首屏 JS 约 123KB gzip（vendor 45 + motion 31 + 应用 46），CSS 4.4KB gzip，字体 107KB（预缓存）。

## 快速开始

```bash
npm install
node scripts/fetch-fonts.mjs   # 从 node_modules 拷贝自托管字体到 public/fonts
node scripts/gen-icons.mjs     # 生成 PWA 图标（无第三方依赖的手写 PNG 编码器）

npm run dev        # 本地开发（无 Service Worker）
npm run build      # 类型检查 + 生产构建 + PWA
npm run preview    # 预览生产构建
npm run test       # 领域层单元测试
```

### 部署到 GitHub Pages

**在线地址：** <https://shawney123.github.io/anchor/>

1. 把仓库推到 GitHub，仓库名建议 `anchor`。
2. **Settings → Pages → Source 选 `GitHub Actions`**。
3. 推送到 `main` 分支即自动构建部署。

`vite.config.ts` 会自动根据 `GITHUB_REPOSITORY` 推导 base 路径（`/anchor/`）。
若绑定了自定义域名，在 workflow 里加 `BASE_PATH: /` 即可。

## 设计原则速查

1. **只做减法** — 每个功能必须减少一个决策选项，而不是增加一条待办
2. **触发点寄生** — 约束挂在必然发生的既有事件上，绝不新增日常动作
3. **失败即数据** — 不出现红叉、扣分、连续天数
4. **豁免必须可见且有永久代价** — 后果写在按钮内部，不是确认弹窗
5. **每日只加一个节点** — RSIP 的引擎，也是产品的节奏
6. **通知只留三类** — 预约到点、链结束、崩塌复盘
7. **主动型国策付维护税** — 系统对"主动型"国策显示维护成本估算，优先推荐被动/半被动
8. **不做社会比较** — 分享只含国策与定式，不暴露失败率

## 已知边界（静态托管的代价）

- **无后台推送**：Web Push 需要服务端发送端，纯静态做不到。预约提醒因此依赖页内倒计时 + 标签页标题倒计时 + Wake Lock 保活 + 可选的页内系统通知。离开页面即失效，这是能力边界，不是 bug。
- **无跨设备同步**：数据只在本机。设置页提供一键导出/导入 .json，另有超过 30 天未备份的提示。
- **Service Worker 会缓存旧版本**：新版本发布后，顶部会出现「发现新版本」提示条，点「立即更新」后才切换。
