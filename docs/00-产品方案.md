## 0. 决策记录（本轮已确认）

| 决策项 | 结论 |

| 原文加固 | 接受：不可豁免清单 + 分级降级 |
| 命名 | **Anchor**（详见设计系统文档） |
| 本轮交付 | 方案与设计文档；代码待评审通过后动手 |

### 静态托管带来的三个硬约束（必须正面解决）

1. **无后端 ⇒ 无推送服务。** 预约倒计时提醒不能依赖 Web Push（VAPID/FCM 需要服务端）。
   → 对策：关键提醒走 **双通道**——页内实时倒计时 + **导出系统日历/闹钟 (.ics)** 作为零依赖兜底。Android 上闹钟是系统级、最可靠。
2. **无后端 ⇒ 无账号、无跨设备同步。**
   → 对策：Local-first 存储 + **一键导出/导入 .json**。这是产品的必需品，不是可选项。GitHub Pages 本身可作为"模板分发"渠道。
3. **无后端 ⇒ 无法安全托管 LLM 密钥。**
   → 对策：AI 能力走 **"AI 共演"模式**——产品生成结构化提示词 → 用户复制到任意 AI → 结果粘回产品校验入库。零密钥、零成本、零隐私外泄（与原文作者自己的建议一致）。

## 1. 定位

**Anchor 是一个约束力工程（Constraint Engineering）产品，不是自律激励产品。**

它把《如何提高自制力：CTDP 与 RSIP》里三个可执行机制——神圣座位、下必为例、线性时延——以及 RSIP 的国策树 / 递归回溯 / 崩塌调试，从人的脑子里搬进系统。

> 不是帮你"变自律"，而是帮你在不依赖意志力的前提下，把有限的约束力资源投在杠杆率最高的几个节点上，并且**永不清零**。

### 反定位（红线，违反即推翻设计）

| ❌ 不做 | 依据 |
|---|---|
| 连续打卡 / 断签羞辱 / 连续天数 | 原文 §7：打卡类策略对长期状态负责，会在宏观尺度被平均掉 |
| To-do List / 任务清单 / 优先级排序 | 原文 §攻略三：主动型国策造成公地悲剧与决策负荷 |
| 意志力肌肉叙事（"你要更自律"） | 原文 §26：幸存者偏差，正是作者最反感的 |
| 鸡汤、每日激励语、AI 心理陪伴 | 不作用于 V(τ)，纯情绪消费 |
| 排行榜、好友对比 | 外部监督不是约束力，反而制造新的"不可逃逸区" |
| 成就徽章墙 / 分数 | 制造新的主动决策负荷 |
| 广告、数据售卖 | 打扰即机制破坏 |
| 宣称"治疗"ADHD / 抑郁 | 原文：严重神经性问题必须走医学途径 |
| 未标注为估算的"科学"数值 | 原文 81%→62% 是举例，产品不得包装成科学 |

### 北极星指标

**约束力资源存量** = 累计点亮的国策节点数 + 累计完成的链节点数。

不追踪 DAU、不追踪打卡率、不追踪停留时长。

## 2. 目标用户

### 主画像
18–35 岁，自责严重但方法反复失败的人。典型语料："收藏了一堆自律方法论，一个都没用起来""晚上刷手机到两点，白天起不来""道理都懂"。

用户**不需要**被教育"为什么要自律"，需要的是**在崩溃之后还能继续，并且知道此刻该做什么**。

### 三档难度自识别（沿用原文"小马过河"）

产品在首次进入时，用用户真实的一周时间线反推其难度档位，并据此调整默认国策的激进程度：

| 档位 | 特征 | 默认策略 |
|---|---|---|
| Easy | 作息基本稳定、偶有拖延 | 只给 3–5 条被动国策，链时长 25min |
| Medium | 拖延明显但能启动 | 标准国策树 + 完整链机制 |
| Hard | 长期失序（作息颠倒/持续拖延） | 从"傻瓜国策"起步，默认走攻略二（农村包围城市），不主动抛高阻力目标 |

> 泛人群定位的风险：Easy 档用户会觉得"过度工程"。**难度自识别 + 默认档位调节**是保住泛人群的关键。

## 3. 核心机制 → 产品形态

| 原文机制 | 产品形态 | 关键设计 | 陷阱 |
|---|---|---|---|
| 神圣座位 | 绑定**实体锚** + 落座/离座两事件 | 只记事件不记待办；质量靠"状态"而非时长 | 沦为第 N 个番茄钟 |
| 下必为例 | **判例引擎**：全局永久豁免表 | 一次允许永久生效，作用于所有链 | 全部豁免 → 需豁免清单可视化 |
| 线性时延 | 预约信号 + 15min 倒计时 | 信号寄生既有动作（桌面小组件/系统闹钟/ICS） | 提醒被无视 → 顺延计成本 |
| 二次启动信号 | 预约 → 缓冲 → 即时信号 | 14:30 死线，留 30s 缓冲 | 过于机械 → 允许一次顺延 |
| 不可逃逸区 | 尺度诊断（首次进入 + 复诊） | 输出白话稳态剧本 + 有效干预节点 | 术语门槛 → 必须翻译成人话 |
| 定式 / 国策 | **国策卡**库 + 设计器 | 四字段：触发/判定/阻力/杠杆率 | 用户"国策贫瘠" → 库 + 设计器兜底 |
| 递归回溯 | **国策树**，每日最多加一个节点 | 栈式回滚：熄父 → 子孙全灭 | 树复杂爆炸 → 分组折叠 |
| 崩塌 | **崩溃复盘（编译器风格）** | 归因五分类 + 一键修正建议 | 变成责备 → 语气必须是系统日志 |
| 内化 | 熟练度持久化（跨崩塌不清零） | Roguelike 元进度 | 被误解为作弊 → 显式解释 |
| 国策组 | 组级容错名额（允许 N 个熄灭） | 组状态 = 子项聚合 | 组过多 → 折叠 |
| 水密隔舱 | 冻结 + 到期一次性重结 | 频率上限防滥用 | 滥用冻结 = 合法逃避 |
| 渐进升级 | 分级降级：失败掉一级而非清零 | L0–L3，L0 才熄灭 | 分级太多算不清 |

## 4. 功能范围

### P0 · 核心循环（必须先跑通）
1. **链**：创建（绑定实体锚）、落座、节点推进、判定中断、链复位
2. **判例引擎**：中断时二选一（判定违规→清链 / 永久允许→全局生效）；永久豁免清单；不可豁免清单
3. **预约**：预约信号 → 倒计时 → 即时信号 → 落座；顺延（限一次）；ICS 兜底提醒
4. **国策树**：点亮（每日一个）、父子关系、栈式回滚、点亮/熄灭状态
5. **本地存储 + 导出/导入**（.json）
6. **熟练度**累计（跨崩塌保留）

### P1 · RSIP 完整语义
7. 国策组 + 容错名额
8. 水密隔舱（冻结/解冻）
9. 分级降级 L0–L3
10. 崩溃复盘（编译器风格 + 五类归因 + 一键修正）
11. **定式库**：预置 30–50 张傻瓜国策卡（先发制人 / 夜幕降临 / 预备仪式 / 电子宵禁 / 陷阱规避 / 神清气爽 / 快速打扫 / 赢麻了 …）
12. 深色/浅色主题、PWA 安装引导

### P2 · 获客与设计能力
13. 尺度诊断（时间线输入 → 稳态剧本 + 干预节点）
14. **AI 共演国策设计器**（提示词生成 → 用户粘回 → 校验入库）
15. 定式卡分享（只分享国策与定式，**不暴露失败率**）

### 明确排除
原生 App 封装、硬件联动、账号体系、云同步、社区 UGC 审核流。

## 5. 验收标准（P0）

| # | 标准 | 判定方式 |
|---|---|---|
| A1 | 从打开到落座 ≤ 3 次点击 | 走查 |
| A2 | 判例弹窗能在 1 次确认内说明"永久"后果 | 走查 + 文案审读 |
| A3 | 链复位后熟练度不丢失 | 单元测试 |
| A4 | 每日点亮节点数硬上限为 1 | 单元测试 |
| A5 | 熄父节点 → 子孙全部熄灭，且各自熟练度保留 | 单元测试 |
| A6 | 导出 .json → 清库 → 导入，状态完全还原 | 往返测试 |
| A7 | Android 典型机型上列表滚动 60fps，页面切换无掉帧 | 实机录屏 |
| A8 | 断网后全部核心功能可用（除 AI 共演的粘贴解析） | 飞行模式测试 |
| A9 | 所有动效可用 `prefers-reduced-motion` 降级 | 系统设置切换 |
| A10 | 系统字号放大到 130% 无内容截断 | 实机 |

## 6. 与原文的关系与 IP

- 原文为 MIT 式授权，可商用；但写明"作者本人参与商业化项目另行约定"。
- 产品内设 **「方法论出处」页**，署名原作者与原文链接。
- 「定式/国策」「神圣座位」「下必为例」「尺度诊断」「不可逃逸区」等源自原文的概念，命名与释义保持出处可追溯。
- **主动联系作者做非正式顾问 / 联合署名**——这是应该认真对待的事，不是可选项。
- **产品调性必须继承原文的态度**（反鸡汤、反自律神话、反幸存者偏差），而不是只继承它的理论。否则做出来就是个换了皮的打卡 App。

## 7. 风险登记

| 风险 | 影响 | 应对 |
|---|---|---|
| 每日"只加一个"的仪式流失 | RSIP 引擎停摆 | 仪式缩到 1 分钟；结算卡直接放首页首屏；连续 2 天未结算 → 温和提醒而非惩罚 |
| 永久豁免被滥用为全合法 | 约束力归零 | 豁免清单可见 + 影响面说明 + 不可豁免清单 + 触发新豁免时展示"当前豁免总数" |
| 泛人群定位导致水土不服 | 留存差 | 难度自识别 + 默认档位调节 + 被动国策优先 |
| 崩塌被解读为失败 | 弃用 | 编译器风格 + 熟练度不清零 + 一键修正建议 |
| 静态托管无推送，提醒失效 | 预约链断裂 | 双通道：页内 + ICS 导出；无推送也能用 |
| 数据仅存本地，设备丢失 | 信任崩塌 | 一键导出 + 月度备份提醒（可关） |
| 中文用户访问 Google Fonts 失败 | 首屏字体闪烁/无衬线 | 自托管 woff2 子集 + 中文系统字体栈 |
| GitHub Pages 单页刷新 404 | 白屏 | hash 路由（`/#/tree`） |
| SW 缓存陈旧导致旧版 | 行为诡异 | SW 版本号 + "发现新版本"提示 |
| 界面动效在低端 Android 掉帧 | 反感 | 只动 transform/opacity；禁大面积 backdrop-filter；动效预算分级 |
