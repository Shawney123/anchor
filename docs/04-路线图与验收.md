## 1. 里程碑

### P0 · 核心循环（4 周）

**目标**：证明"每天点亮一个国策 + 判例引擎"这个循环能跑起来，且用户愿意每天回来结算。

**范围**
- 链：创建（绑定实体锚）、落座、节点推进、结束、判定中断、复位
- 判例引擎：永久豁免二选一、豁免清单、不可豁免清单、今日放行记录
- 预约：信号 → 15min 倒计时 → 即时信号 → 落座；顺延一次；ICS 兜底
- 国策树：点亮（每日一个）、父子挂接、栈式回滚、熟练度累积
- 本地存储（事件日志）+ 导出/导入 .json
- 今日结算 + 一句话复盘
- 设计系统落地：字体/色彩/间距/组件/动效（12 条关键动效）
- PWA：manifest + SW + 安装引导 + 版本提示

**不做**：AI、稳态诊断、定式库（只有内置几条种子）、国策组、水密隔舱、分级降级、崩塌复盘。

**验收**
| # | 标准 |
|---|---|
| A1 | 从冷启动到落座 ≤ 3 次点击 |
| A2 | 判例弹层一次确认内说明"永久"后果 |
| A3 | 链复位后熟练度不丢失 |
| A4 | 每日点亮硬上限 1（领域层测试） |
| A5 | 熄父 → 子孙全熄，各自熟练度保留（领域层测试） |
| A6 | 导出 → 清库 → 导入，状态完全还原（往返测试） |
| A7 | 中端 Android 实机 60fps，无掉帧 |
| A8 | 断网可用 |
| A9 | `prefers-reduced-motion` 降级生效 |
| A10 | 系统字号 130% 不截断 |

**核心假设与判定**
| 假设 | 观测指标 | 判定 |
|---|---|---|
| 用户愿意每天只点亮一个国策 | 首次结算率 / 7 日回访 | < 30% 则仪式设计需重构 |
| "永久允许"能改变行为 | 豁免授予后的次日失约率 vs 未授予组 | 无差异则判例机制失效，需重做交互 |
| 崩塌后重建不流失 | 崩塌后 7 日回访率 | < 50% 则需强化熟练度与"调试器"叙事 |

### P1 · RSIP 完整语义（4 周）

**范围**
- 国策组 + 容错名额（组状态 = 子项聚合）
- 水密隔舱：冻结 / 到期一次性重结（带频率上限）
- 分级降级 L0–L3
- 崩塌复盘：编译器风格 UI + 五类归因 + 一键修正
- 熟练度可视化（进度环、节点角标）+ 熟练度不丢失的解释文案
- 定式库首批 30–50 张（取自原文现成例子）
- 树视图 / 列表视图切换；节点拖拽换挂
- 难度档位自识别与默认国策强度调节

**验收**
| # | 标准 |
|---|---|
| B1 | 组容错：N 个熄灭时组仍点亮，第 N+1 个熄灭触发组熄 + 子孙熄 |
| B2 | 水密隔舱到期：当天满足的解冻、未满足的严格熄灭 |
| B3 | 分级降级：失败降一级，L0 才熄灭，熟练度不变 |
| B4 | 崩塌复盘归因准确率（人工标注 30 例，≥ 70% 命中正确类别） |
| B5 | 30 张定式卡全部可在 1 分钟内完成配置 |
| B6 | 树 100 节点仍可流畅交互（折叠 + 虚拟化） |

### P2 · 获客与设计能力（4 周）

**范围**
- 尺度诊断：昨日时间线输入 → 日/周级稳态剧本 + 有效干预节点
- 本地候选引擎（规则版定式生成）
- AI 共演设计器：提示词生成 → 复制 → 粘贴 → 校验 → 候选卡
- 分享：国策树/定式卡（`navigator.share`），**只含正向内容**
- 稳态诊断历史（周级复诊）
- 方法论出处页（署名原作者与原文链接）

**验收**
| # | 标准 |
|---|---|
| C1 | 诊断输出含日级 + 周级两个尺度的稳态剧本 |
| C2 | 候选引擎对 20 个典型问题，top3 中至少 1 个被人工判定"确实可用" |
| C3 | AI 共演 JSON 解析成功率 ≥ 90%，失败时给出字段级错误 |
| C4 | 分享内容不含失败率/中断历史/熟练度百分比（逐项检查） |

## 3. 风险登记与预案

| 风险 | 触发信号 | 预案 |
|---|---|---|
| 每日仪式流失 | 结算率 < 30% | 仪式压缩到"一次点击"；结算卡做首页唯一主 CTA；连续 2 天未结算 → 温和提示而非惩罚 |
| 永久豁免被滥用 | 豁免总数 > 6 或放行次数增长过快 | 豁免清单顶部显示总数与"削弱了 N 条判定标准"；授予时展示当前豁免总数；触发不可豁免清单 |
| 崩塌被当成失败 | 复盘页跳出率高 | 语气全面改为系统日志；熟练度不清零可视化；提供一键修正而非只报错 |
| 泛人群水土不服 | Easy 档用户流失 | 难度自识别生效；Easy 档默认只给 3–5 条被动国策；提供"轻量模式"开关（隐藏树，只留链 + 今日） |
| 静态托管能力边界被误解 | 用户反馈"收不到提醒" | 在设置页与 README 明写边界；ICS 兜底引导做两次（首次 + 首次失败后） |
| 数据丢失 | 设备更换/清除缓存 | 一键导出 + 月度提醒 + 导出文件内嵌产品信息便于用户找回 |
| 字体加载失败 | 首屏字体闪烁 | 系统字体栈作为最终回退，`font-display: swap`，本地预加载西文关键字重 |
| SW 陈旧版本 | 行为与 UI 不一致 | `registerType:'prompt'` + 顶部"发现新版本"条 |
| 内容与原文立场背离 | 出现"打卡""坚持""自律"等词 | 建立**禁用词检查表**，进入评审 checklist |
